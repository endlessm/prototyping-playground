---
title: Documentation standards
description: Documentation standards guidance for the Endless team.
---

Choose the canonical owner using [Responsibilities](contracts-and-instructions.md). Context documents use title and description frontmatter, with H2 body headings. Skills use name and description frontmatter; the name matches the lowercase hyphenated folder. READMEs serve as owner indexes.

Write direct actions with observable completion criteria. Put the condition before its action. Link substantial conditional reference instead of copying it. Keep one canonical meaning per source. Match vocabulary to GLOSSARY.md. Distinguish facts, assumptions and missing information.

Write the Manual as a human reference for controls, consequences and recovery. Keep detailed schemas and command contracts with their code owner. Verify links, examples, route triggers and disabled-module behavior. Update guidance when behavior changes.
