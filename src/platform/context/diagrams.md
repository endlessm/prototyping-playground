---
title: Mermaid diagrams
description: Mermaid diagrams guidance for the Endless team.
---

Use a Mermaid fence in a document or a standalone diagram through the enabled diagrams module. Read that module's README and create-diagram skill before editing its file format.

Include accTitle and accDescr. Keep labels short and contrast legible in light and dark modes; use the shared renderer's theme instead of hardcoded text colors. Verify valid syntax and readable render errors. Canvases embed diagram artifacts by permanent address. Renderer serialization and theme handling belong to the diagrams module.
