Platform context and cross-module skills live in src/platform/. Module READMEs, context and skills live in src/modules/<id>/. System guidance lives in src/systems/<id>/. Root AGENTS.md holds common requirements and module routes. Technical declarations live beside code in tooling/.

Choose the source that owns the behavior. Keep facts and standing requirements in context; put repeatable task decisions in skills. Human Manual pages belong to src/modules/documentation/pages/. Context and Skills displays canonical sources, rather than maintaining copies.

Change implementation and its authoritative guidance together. Module skills stay with their module and system skills apply only to that system. See [Documentation standards](documentation-standards.md) and [Agent context routing](agent-context.md).
