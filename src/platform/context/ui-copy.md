---
title: Studio UI copy
description: Studio UI copy guidance for the Endless team.
---

Use plain, direct English in i18n/locales/en.json. Name the action and its object. Keep labels short and consistent with visible controls and GLOSSARY.md.

Use separate sentences instead of semicolons joining sentences. Action labels have no trailing ellipsis. Write lo-fi and hi-fi consistently. Pending labels describe the current action plainly: Saving, Creating, Moving. Confirm a completed action with a concise toast; errors explain the problem and a useful next action. Match shortcut labels and file-reveal wording to the person's operating system.
