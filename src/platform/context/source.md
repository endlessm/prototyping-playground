---
title: Editing and saving
description: Editing and saving guidance for the Endless team.
---

Source editing is local only. Open Edit source on an artifact, save explicitly and resolve a conflict by reviewing the latest file before overwriting. Leaving with unsaved edits needs a warning. The deployed site offers reading and sharing, without source mutation.

Use Open in editor or the operating system's reveal action when available. Label reveal as Show in Explorer on Windows, Reveal in Finder on macOS and Show in folder on Linux. Copy link uses the permanent address; Copy path identifies the current file location. File-service permission and identity checks remain authoritative.

Saves preserve both the view's permanent identity and named-state identities. Rename a named state with its existing marker and declaration together; never drop or replace a marker while editing source.
