# Contributing

Endless Design Studio is the Endless team's prototyping sandbox. Team members work in it with their coding agents; see the [README](README.md) to run it and the Manual inside the studio for how to work in it.

Report a bug or suggest a change in a [GitHub issue](https://github.com/endlessm/design-studio/issues). Changes go through pull requests on `main`, and the checks in `.github/workflows/checks.yml` must pass.
